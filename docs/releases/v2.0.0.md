# Portiva v2.0.0

Portiva 2 使用 Rust + GPUI 重建 SSH / SFTP 工作台，提供独立的本地终端与多会话界面。

- SSH：密码、私钥与 Agent 认证、主机指纹确认、会话标签、嵌套终端分屏，以及可选的 X11 转发。
- SFTP：本地/远端双栏、递归目录传输、进度、暂停/继续、取消、冲突处理与失败重试。
- 终端：ANSI / 真彩色、中文与输入法、复制粘贴、50,000 行历史、日志与代码高亮、远端任务标题。
- 桌面：深浅主题、背景图、字体与配色、快捷键、自动保存设置和服务器资源状态。
- 更新：在“设置 → 关于”检查 GitHub Releases 的 2.x 稳定版，按平台下载、显示进度并验证 SHA-256。Windows / Linux 便携版可安装并重启；Linux 系统版及 macOS 打开对应安装包。活动会话与传输会阻止安装。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `Portiva_2.0.0_windows_x64.zip`，解压后运行 `portiva2.exe` |
| Linux AMD64 | `Portiva_2.0.0_linux_amd64.deb` / `.tar.gz` |
| Linux ARM64 | `Portiva_2.0.0_linux_arm64.deb` / `.tar.gz` |
| macOS Apple Silicon | `Portiva_2.0.0_macos_arm64.dmg` / `.app.tar.gz` |

四个平台均使用对应架构的原生 GitHub Actions 环境进行优化构建和工作区测试。`SHA256SUMS.txt` 包含全部附件的 SHA-256。

Linux 官方包以 Ubuntu 24.04（glibc 2.39）为基线，需 Vulkan 驱动及 X11 / Wayland 桌面。Debian 系发行版可用 `sudo apt install ./Portiva_2.0.0_linux_amd64.deb` 安装；ARM64 对应替换文件名。便携包解压后运行目录内的 `./portiva2`，系统运行库依赖见项目说明。

macOS 最低版本为 13，打开 DMG 后将 `Portiva.app` 拖入“应用程序”。应用使用 ad-hoc 签名，尚未经过 Apple 公证。

## 从 1.x 升级

2.x 的配置与凭据使用独立的 `Portiva2` 目录和系统凭据条目，暂不自动导入 1.x。旧版串口功能尚未包含在 2.x 中。保留 1.x 数据，手动下载并启动 2.x 即可并行使用。

此版本的 `latest.json` 原样保留 v1.15.1 的已签名更新清单，供已安装的 1.x 应用继续检查自身更新；它不用于安装 Portiva 2。2.x 更新器读取 GitHub Releases 附件 `update-v2.json` 和 `SHA256SUMS.txt`，只接受当前仓库的对应版本附件，不读取旧版清单，也不依赖 GitHub API 匿名请求额度。

X11 转发需要另外安装本机显示服务（Windows：VcXsrv；macOS：XQuartz；Linux：X11/XWayland），并在远端启用 X11 转发。协议回环测试不能代替真实远程图形窗口、系统输入法和所有全屏终端应用的实机联调。
