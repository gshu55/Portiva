# X11 转发

在 SSH 连接配置中点击显示器图标启用 X11 转发，保存并连接。图标启用时高亮，悬停显示开启或关闭操作。新建和旧配置默认关闭；修改现有配置后重新建立连接生效。每个 SSH 分屏都会单独申请 X11 转发，远程图形程序的窗口显示在本机 X Server 中。

## 本机显示服务

| 平台 | 准备 | 自动发现 |
| --- | --- | --- |
| Windows | 安装 VcXsrv；也可以使用已经运行的兼容 X Server | 优先使用配置的显示地址或进程 `DISPLAY`。两者为空时，从标准安装目录及 `PATH` 查找 VcXsrv，按需启动应用管理的显示服务 |
| Linux | 使用现有 X11 或 XWayland，并安装 `xauth` | 读取 `DISPLAY`；支持 `:0`、`unix:0`、`unix/:0`、`hostname/unix:0` 的本地域套接字，以及显式 TCP 显示 |
| macOS Apple Silicon | 安装并启动 XQuartz | 优先使用 `DISPLAY`，缺失时通过 `launchctl getenv DISPLAY` 读取 XQuartz 的显示地址；使用其 launchd 本地域套接字 |

“本机显示”留空表示自动检测，也可填写 `localhost:0`、`127.0.0.1:0.1`、`[::1]:0` 或 Unix/XQuartz 的显示地址。端口由 `6000 + 显示编号` 得到；句点后的数字是屏幕号，不是端口。应用不修改系统 `DISPLAY`。

已有显示服务的认证由 `xauth list <display>` 读取，只接受 `MIT-MAGIC-COOKIE-1`。Linux 使用 `PATH` 中的 `xauth`，macOS 使用 `/opt/X11/bin/xauth`，Windows 优先使用 VcXsrv 同目录的 `xauth.exe`，再回退 `PATH`。`XAUTHORITY` 沿用当前应用进程的环境。认证信息只留在内存，不写入连接配置。

Windows 管理的 VcXsrv 使用随机显示号、临时认证文件和独立 cookie，启用多窗口与剪贴板，不使用 `-ac`。相同显示配置的 SSH 连接共用本机显示服务，但不共用转发认证。最后一个使用者关闭后结束应用自行启动的服务；Windows Job 在应用意外退出时也会结束它。应用不结束用户独立启动的显示服务。VcXsrv 和 XQuartz 需要另外安装，不包含在 `portiva2.exe` 中。

## 远程服务器

SSH 服务器需要支持 X11 转发，并配置 `xauth`。以 OpenSSH 为例，需要启用 `X11Forwarding yes`，并让 `XAuthLocation` 指向服务器上有效的 `xauth`。应用会请求转发并等待服务器确认；拒绝时显示具体错误，不把未成功建立的转发标记为可用。

连接后可以在远程终端检查：

```sh
echo "$DISPLAY"
xclock
```

远程 `DISPLAY` 由 SSH 服务器分配，常见形式是 `localhost:10.0`，无需手动设为本机显示地址。`xclock` 仅用于示例，需要服务器已经安装对应程序。纯 SFTP 连接和本地终端不申请 SSH X11 转发。

## 认证与生命周期

每个终端生成独立的随机转发 cookie，只把该 cookie 发给 SSH 服务器。收到 X11 反向通道后，先校验协议、版本、长度和 cookie，再用本机的认证信息重建握手，随后双向转发。支持大小端和分片握手；未注册、其他 SSH 连接及已撤销的 cookie 会在连接本机显示服务前被拒绝。

关闭某个分屏会撤销其 cookie 并关闭对应图形通道，其余分屏和连接继续工作。SSH 断开会取消全部关联通道，包括还未完成握手的连接。每条 SSH 连接最多允许 64 条并行 X11 通道，认证握手及本机连接具有超时。

这是面向用户信任的远程图形程序的转发，不实现 X11 SECURITY 扩展的“不可信客户端”隔离。

## 验证范围

Windows 已通过合成 X Server 与真实回环 SSH 协议的集成测试，覆盖转发协商、认证替换、分屏/连接隔离、双向传输、取消、失败和 SSH/SFTP 并行工作。默认测试不启动真实图形服务，也不读取用户私钥或写入系统凭据库。

本机没有安装 VcXsrv，尚未验证真实远程图形窗口。Linux AMD64 / ARM64 和 macOS ARM64 的原生 Release 编译、协议回环及 Unix 套接字单测由发布流水线校验；真实 X11 / XWayland / XQuartz 图形服务仍需在对应系统验收。
