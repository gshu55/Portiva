# Portiva 安全声明

最后更新：2026 年 8 月 13 日

## 凭据存储

- SSH/SFTP 密码、私钥口令和代理密码使用操作系统安全存储。
- HTTP 请求认证字段按当前产品约定随本地请求草稿明文保存，使用共享设备时应特别注意本机访问权限。
- Portiva 不会在界面中回显已保存的系统凭据内容。

## SSH 主机校验

- Portiva 会校验 SSH 主机密钥，并保存用户确认过的已知主机记录。
- 主机密钥发生变化会被视为高风险事件。在确认变更原因和新指纹前，不应继续连接。
- 删除已知主机记录后，下次连接需要重新确认主机指纹。

## 非加密协议

Telnet、Raw TCP、FTP 等协议不提供与 SSH、SFTP 或 HTTPS 相同的传输保护。关闭风险提示不会改善协议本身的安全性。

## 本机安全边界

本机配置、请求草稿、日志和导出文件由当前操作系统账户保护。用户应妥善管理设备登录权限、磁盘加密、备份和共享目录。

## 日志与信息暴露

Portiva 会对已知敏感字段进行日志脱敏，但无法保证识别任意自定义内容。共享日志、终端输出或截图前，应再次检查其中是否包含密码、令牌、主机信息或业务数据。

## 安全责任

连接工具无法替代操作系统、网络边界和组织安全策略。用户应根据目标环境采用最小权限、可信网络、及时更新和独立备份等保护措施。
