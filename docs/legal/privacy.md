# Portiva 隐私声明

最后更新：2026 年 8 月 13 日

本声明说明 Portiva 在桌面端处理本地数据、系统权限和日志信息的基本边界。

## 本地数据

- 连接配置、工作区设置、已知主机记录和凭据元数据默认保存在本机。
- SSH/SFTP 密码、私钥口令及代理密码使用操作系统安全存储；应用设置文件不保存这些密码明文。
- HTTP 请求认证字段按当前产品约定随本地请求草稿保存，请在共享设备上谨慎使用。

## 网络与内容

- 终端内容、HTTP 请求数据、文件传输路径和日志不会由 Portiva 自动上传到任何远程服务。
- 用户主动建立连接、发送请求、传输文件或检查更新时，相关数据会发送到用户选择的目标服务。
- Portiva 的软件更新功能会访问项目配置的 GitHub Release 更新地址。

## 系统权限

剪贴板、文件系统、网络连接、串口和密钥访问仅在用户主动执行相关操作时使用。具体权限仍受当前操作系统账户和系统安全策略约束。

## 日志与共享

敏感字段会在本地日志处理中进行脱敏，但用户仍应避免在共享屏幕、截图或导出的日志中暴露密码、令牌、私钥和其他私密信息。

## 声明更新

本声明可能随功能和数据处理方式调整而更新。最新版本以本页面内容为准。
