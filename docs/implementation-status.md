## 跨平台 X11 转发（2026-11-28）

- 从原 Portiva 的 X11 服务复用显示发现、握手与认证替换代码，适配为无 GPUI 依赖的核心模块。SSH 在 Shell 启动前发送 `x11-req` 并等待确认；资源采样、SFTP 和本地终端不申请转发。
- 每个 PTY 使用独立的随机转发 cookie，校验后才连接本机显示服务并重建认证握手。兼容大小端和分片，拒绝其他 SSH 连接及已撤销 cookie；关闭分屏或断开 SSH 会关闭关联的双向图形通道。每条 SSH 连接限制 64 条并行 X11 通道，握手与本机连接带超时。
- Windows 可按需启动已安装的 VcXsrv，使用临时 Xauthority、认证保护和 Job 生命周期，不禁用访问控制。相同配置共用本机显示服务，最后一个使用者离开后释放应用自行启动的进程；已有外部显示服务由用户管理。辅助进程不创建命令行黑窗口。
- Linux 通过 DISPLAY 对接 X11/XWayland，支持本地域套接字及 TCP。macOS 对接 XQuartz 的 launchd 套接字，缺失进程环境时通过 launchctl 查询 DISPLAY。认证复用平台 xauth，凭据不写入连接配置。
- 连接表单增加 X11 开关及可选本机显示地址，旧配置默认关闭。认证切换保留 X11 地址，切到 SFTP 时关闭 X11；选项保存后重新连接生效。新增绘制部分单独封装，保留此前的轻量弹窗分派。

## 已落地的边界

## 分屏、会话工具栏与资源底栏（2026-11-27）

- 连接顶部统一采用图标按钮：双栏文件/显示终端、SFTP 收起/展开、左右拆分、上下拆分和当前连接的传输队列。关闭按钮位于每个终端自己的标题栏，按该分屏 ID 关闭；关闭未聚焦的分屏保持当前终端和焦点。按钮带中文悬停说明；最后一个终端和拆分期间的关闭按钮禁用，业务入口同样守卫。
